📏 The Section Formula

Slicing line segments into perfect ratios!

Dividing the Line

The Section Formula allows us to find the exact coordinates of a point P that divides a line segment connecting points A(x₁, y₁) and B(x₂, y₂) into a specific ratio of m : n.

Type of Division The Formula When to Use It
Internal Division x = (mx₂ + nx₁) / (m + n)
y = (my₂ + ny₁) / (m + n)		 When point P lies strictly between point A and point B.
External Division x = (mx₂ - nx₁) / (m - n)
y = (my₂ - ny₁) / (m - n)		 When point P lies on the line passing through A and B, but sits outside the actual segment AB.

✂️ 1. The Internal Divider

Adjust the ratio m:n. Watch how point P slides along the segment AB, recalculating its exact coordinate position based on the Internal Section Formula!

Internal Coordinate P(x, y) P = ( (2(7) + 3(-8)) / 5 , (2(6) + 3(-4)) / 5 ) P(-2, 0)

🚀 2. The External Divider

Here, P is placed outside the bounds of A and B. Notice how the formula requires a subtraction! If m = n, the lines become parallel and point P mathematically shoots off to infinity.

External Coordinate P(x, y) P = ( (4(2) - 2(-2)) / 2 , (4(2) - 2(-2)) / 2 ) P(6, 6)

Not sure which formula to use? Slide point P across the infinite 2D line passing through A and B. Observe how crossing the boundaries instantly flips the math context!

🧠 Test Your Knowledge

Q1: Find the coordinates of point P which divides the line segment joining A(4, -3) and B(8, 5) internally in the ratio 3:1.
Step 1: Identify the values: x₁ = 4, y₁ = -3, x₂ = 8, y₂ = 5, m = 3, n = 1.
Step 2: Apply the Internal Section Formula for the x-coordinate:
x = (mx₂ + nx₁) / (m + n) = (3(8) + 1(4)) / (3 + 1) = (24 + 4) / 4 = 28 / 4 = 7.
Step 3: Apply the formula for the y-coordinate:
y = (my₂ + ny₁) / (m + n) = (3(5) + 1(-3)) / (3 + 1) = (15 - 3) / 4 = 12 / 4 = 3.
Final Answer: P(7, 3)
Q2: Find the midpoint of the line segment joining the points (-2, 8) and (-6, -4).
Step 1: The midpoint divides a segment exactly in half, meaning the ratio is 1:1 (m = 1, n = 1).
Step 2: Use the simplified midpoint formula: x = (x₁ + x₂) / 2 and y = (y₁ + y₂) / 2.
Step 3: Calculate x: (-2 + -6) / 2 = -8 / 2 = -4.
Step 4: Calculate y: (8 + -4) / 2 = 4 / 2 = 2.
Final Answer: The midpoint is (-4, 2).
