⚖️ Linear Equations in Two Variables

When one unknown just isn't enough to solve the puzzle!

The Standard Form

In previous chapters, we solved equations with just one missing piece (like 2x + 5 = 9). But real life is rarely that simple. Often, two different quantities depend on each other. To describe these relationships, we use Linear Equations in Two Variables.

Component Definition & Role
The Standard Form ax + by + c = 0
This is the universally accepted format for writing these equations.
The Variables (x, y) The two unknown quantities that can change.
The Coefficients (a, b) Real numbers multiplying the variables. The only rule is that a and b cannot both be zero at the same time.
The Constant (c) A fixed real number without any variable attached to it.

⚖️ 1. The Solution Balancer

A "solution" to a two-variable equation is simply a pair of values (x, y) that makes the Left Hand Side exactly equal to the Right Hand Side. Define your own equation by setting the coefficients a, b, and constant c, then slide the x and y values to balance it!

2x + 3y = 12
Left Hand Side (LHS) 2(x) + 3(y) 2(0) + 3(0) 0
≠
Right Hand Side (RHS) Constant (c) -- 12
⚠️ Unbalanced! Keep trying.

♾️ 2. The Infinite Solutions Generator

Unlike an equation with one variable (which usually has exactly one solution), a linear equation in two variables has infinitely many solutions! Pick any random number for x, and the math will magically calculate the perfect y to balance it.

Equation: x + 2y = 6
Rearrange to solve for y: 2y = 6 - x   ➡️   y = (6 - x) / 2
Step-by-Step Calculation: y = (6 - 0) / 2 = 6 / 2 y = 3
Valid Solution Pair: (0, 3)

🧠 Test Your Knowledge

Q1: Can we express a one-variable equation like x = 5 as a two-variable equation?
Yes, absolutely!

Step 1: Start with x = 5.
Step 2: Move everything to one side to approach standard form: x - 5 = 0.
Step 3: We are missing a "y". But we know that zero times anything is zero. So we can add 0y.
Final Answer: 1x + 0y - 5 = 0
Q2: Identify the coefficients a, b, and constant c for the equation: 2x = y.
Step 1: The equation must first be written in standard form: ax + by + c = 0.
Step 2: Move 'y' to the left side: 2x - y = 0.
Step 3: Now match it to the standard format. There is no constant number visible, which means c = 0.
Final Answer: a = 2, b = -1, and c = 0.
