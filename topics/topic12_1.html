📈 Data Representation

Turning raw numbers into compelling visual stories!

The Visual Data Toolbelt

Graph Type Best Used For Visual Characteristics
Bar Graph Categorical or discrete data (e.g., Favorite colors, types of pets). Rectangular bars with equal spacing (gaps) between them.
Histogram Continuous grouped data (e.g., Height ranges, age brackets). Contiguous rectangular bars with no gaps. Area is proportional to frequency.
Frequency Polygon Showing the shape of continuous data distributions. A line graph drawn by joining the midpoints (class marks) of the histogram bars.

📊 1. Bar Graph vs. Histogram

Toggle between Categorical Data and Continuous Data. Notice how the x-axis labels change and the gaps between the bars disappear when the data becomes continuous!

Notice the gaps? Categorical data blocks are distinct and separate.

📉 2. Frequency Polygon Tracer

A frequency polygon is drawn by plotting a point at the Class Mark (Midpoint) of each histogram bar, and connecting them with straight lines. Don't forget to anchor the polygon to the x-axis at the start and end!

🧠 Test Your Knowledge

Q1: How do you calculate the "Class Mark" for drawing a frequency polygon if the class interval is 40-50?
45

The class mark is the exact midpoint of the class interval.
Formula: (Upper Limit + Lower Limit) / 2
(50 + 40) / 2 = 90 / 2 = 45.
Q2: Why do we add an extra class interval at the beginning and end of a frequency polygon that touch the x-axis?
To enclose the area!

A "polygon" is a closed geometric shape. By assuming a class interval before the first data point and after the last data point with a frequency of exactly 0, we anchor the line to the x-axis, closing the shape and completing the polygon.
