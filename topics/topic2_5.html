🧬 Algebraic Identities

Universal mathematical truths that never change!

The Core Identities

An identity is an algebraic equation that is true for all values of the variables occurring in it. Memorizing these standard identities acts as a master key for expanding polynomials and factoring complex equations.

Identity Name The Formula
Identity I (Perfect Square Sum) (x + y)² = x² + 2xy + y²
Identity II (Perfect Square Diff) (x - y)² = x² - 2xy + y²
Identity III (Difference of Squares) x² - y² = (x + y)(x - y)
Identity IV (Standard Product) (x + a)(x + b) = x² + (a + b)x + ab
Identity V (Conditional Cubic) If x + y + z = 0, then x³ + y³ + z³ = 3xyz

📐 1. Visual Proof: (x + y)²

Algebra represents real geometry! The formula (x + y)² = x² + 2xy + y² calculates the area of a square with side length (x + y). Adjust the sizes of x and y to see how the 4 internal boxes always perfectly add up.

Total Area Equation
(x + y)² = x² + xy + xy + y²
(5 + 3)² = 25 + 15 + 15 + 9

✂️ 2. Visual Proof: x² - y²

What happens when you take a big square (x²) and cut a smaller square (y²) out of the corner? You get an L-shape! If you slice that L-shape and rearrange the pieces, they perfectly form a rectangle of width (x + y) and height (x - y).

x² - y² = (x + y)(x - y)
8² - 4² = (8 + 4)(8 - 4) ➡️ 64 - 16 = (12)(4) = 48

🧠 Test Your Knowledge

Q1: Evaluate 102² without directly multiplying 102 × 102.
Step 1: Break 102 into a simpler addition sum: (100 + 2)².
Step 2: Apply Identity I: (x + y)² = x² + 2xy + y² where x=100, y=2.
Step 3: Expand.
(100)² + 2(100)(2) + (2)²
10000 + 400 + 4
Final Answer: 10404
Q2: Factorize the expression: 49x² - 64y².
Step 1: Recognize that this is a "Difference of Squares" matching Identity III: a² - b².
Step 2: Find the square roots of each term.
The square root of 49x² is 7x.
The square root of 64y² is 8y.
Step 3: Rewrite using the pattern (a + b)(a - b).
Final Answer: (7x + 8y)(7x - 8y)
